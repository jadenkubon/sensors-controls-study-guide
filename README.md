# Sensors &amp; Motor Controls — Test 1 &amp; 2 Review

A single-page study tool built from two graded course tests. No build step, no dependencies —
one self-contained `index.html`.

**Live:** https://jadenkubon.github.io/sensors-controls-study-guide/

## What's in it

Three tabs:

**Study Guide** — all 83 captured questions from both tests, in order, with the keyed answer
highlighted and a one-line explanation. Filter by test, hide answers to self-test, show only the
questions that were missed, or search the full text. Figures and truth tables are redrawn as SVG.

**Concept Sheet** — 19 blocks covering the material, each one idea plus the distinction the test
hangs on. Diagrams for shock-current levels, ladder rung anatomy, SPST/SPDT/DPST/DPDT,
photoelectric sensing modes, relay → contactor → starter, the five logic gate symbols, all five
truth tables, and logic gates drawn as contact rungs.

**Flashcards** — 93 cards across 6 decks. Click or `Space` to flip, `←` / `→` to move, `S` to shuffle.

## Notes on the source material

- **Test 2's PDF export is truncated.** It stops partway through question 39, so that question's
  remaining options and all of question 40 were never captured. The score arithmetic
  (35.87 ÷ 40 = 89.68%) confirms the test had 40 questions. Both gaps are flagged in the guide.
- **Test 2's PDF marks the selected answer, not the key.** For the four questions answered
  incorrectly, the correct answer was derived and the reasoning is stated in that question's note.
  Question 1 is the one worth verifying against the textbook.

## Running it

Open `index.html` in any browser. It respects your system light/dark preference and has a manual
theme toggle.
